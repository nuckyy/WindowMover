# WindowMover
Kevyt Windows-työkalu aktiivisen ikkunan siirtämiseen näyttöjen välillä globaalilla pikanäppäimellä.

WindowMover on kevyt Windowsin ilmaisinalueella toimiva apuohjelma. Se siirtää aktiivisen ikkunan seuraavalle näytölle pikanäppäimellä **Ctrl + Alt + M** ja säilyttää ikkunan koon, suhteellisen sijainnin sekä maksimoidun tilan.

Lataa uusin valmis versio repositoryn **Releases**-osiosta.
